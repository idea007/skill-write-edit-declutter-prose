# 词句参考

以下表达是检查线索。先判断它在当前句子里提供了什么信息，再决定删、换或保留；不要执行全文查找替换。

## 铺垫与强调

| 候选表达 | 编辑判断 |
| --- | --- |
| 在当今……的时代、随着……的发展 | 背景与结论无关时直接进入内容；真实的时间变化和因果背景要保留。 |
| 值得注意的是、需要强调的是、不难发现 | 可以直接写后面的事实；提醒涉及风险或条件时，保留提醒的内容和强度。 |
| 说到底、真正的问题是、本质上 | 后文能指出具体问题时直说；没有依据时不能把推测改成定论。 |
| 让我们一起、接下来我将、本文将深入探讨 | 普通正文可以直接展开；教程、议程和长文导航需要时保留。 |
| 毫无疑问、显而易见、众所周知 | 删去无依据的确定性；不能把原本有证据支持的结论反向改成猜测。 |
| Here's the thing、Let me be clear、It's worth noting | 通常可以直接写事实；人物对白或作者有意保留的语气按文体处理。 |
| At its core、In today's landscape、At the end of the day | 指明具体处境，或删除没有信息的框架。 |
| Let that sink in、Full stop、This matters because | 去掉表演式强调；后面给出的真实后果或理由仍需保留。 |

## 空泛术语与抽象判断

“赋能、抓手、闭环、重塑、颠覆、全方位提升”和 navigate、unpack、game-changer 等词需要结合语境判断。原稿提供了执行者、动作或结果时，优先用这些信息解释。术语有明确业务定义时保留；没有具体信息时指出缺口，不凭空补成“增长三倍”等细节。

“影响深远”“意义重大”“The implications are significant”若后面已有影响，可以直接写影响。只有评价而没有依据时，保留为作者评价或建议补充依据，不能替作者制造事实。

## 动词与动作强度

“对报告进行核对”可以改为“核对报告”，直接写出动作。替换后仍应保留对象、程度、频率和结果；不能把“尝试修复”改成“修复”，也不能把“快步走过”改成“飞奔而过”。副词提供独立信息时可以保留，不要求所有动作都压缩成一个词。

## 行话与外语

根据受众和词语的用途决定是否改写。面向普通读者时，onboarding 流程可以写成“新用户引导流程”；若 Onboarding 是界面按钮名，则应原样保留，便于读者找到它。必要术语可以简短解释，解释依赖未知的产品机制时不要自行补写。

## 修饰词与限定词

“非常、真的、实际上”和 really、deeply、actually 等词可能只是重复强调，也可能表达情绪、程度或纠错。删去后含义、强度或作者声音改变，就应保留。

| 必须核对的表达 | 承载的信息 |
| --- | --- |
| 可能、也许、预计、may、might、likely | 不确定性和预测。 |
| 仅、至少、至多、only、at least、at most | 数量或适用范围。 |
| 部分、大多数、通常、some、most、usually | 频率、比例和总体范围。 |
| 尚未、仍然、不再、not yet、still、no longer | 时间状态和否定。 |
| 如果、除非、只要、只有……才，以及 if、unless、as long as、only if | 条件和例外。核对条件方向，尤其是「只要」与「只有……才」的区别。 |
| 愿意、不愿、不一定，以及 is willing to、is unwilling to、does not necessarily | 意愿和逻辑限定。区分意愿与实际行为，保留不确定性。 |

“大多数团队有此问题”不能改成“所有团队都有此问题”，也不能通过删掉“大多数”悄悄扩大范围。对原稿中缺乏依据的“所有、从不、一定”指出疑点，不自行发明一个比例。

## 结构问题

同一个词反复出现但没有赘余时，不必为了换词而改变术语。词句已经准确却仍显得机械时，转读 [结构与句式参考](structures.md)；对改写是否保留原意有疑问时，读 [改写示例](examples.md)。
