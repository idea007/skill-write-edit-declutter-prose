# 结构与句式参考

## 全文结构与作者声音

先理解各段承担的背景、观点、例子、转折或结论作用，再处理重复和衔接。相同观点多次出现时可合并；新增事实、不同例子或有意的呼应仍有作用，不能只因措辞相似就删除。调整段落时保留时间、因果、条件和论证关系，不增补原文没有的论点或结论。

第一人称身份、个人经历和幽默是作者声音的一部分。不能把“我遇到过”改成“大家都会遇到”，也不把个人评价改成普遍结论。口语、情绪和比喻是否保留，取决于它们在全文中的作用。

## 句式判断

判断句式是否在传递信息。相同结构连续出现、没有事实支撑或只制造戏剧性时可以调整；单次出现不能作为删除依据。

## 对比与否定

“不是 X，而是 Y”“The answer isn't X. It's Y.”若只是引出 Y，可以直接陈述 Y。X 若纠正误解、排除错误原因、说明权限或保留限制，应保留相应信息。

“不是所有成员都能使用”不能改成“成员都能使用”；“不支持自动发布”不能为了减少否定而改成“支持发布”。合并否定排比时，也要保留其中每个实际排除项。

## 设问、碎句与收尾

| 候选结构 | 编辑判断 |
| --- | --- |
| 你知道吗？答案其实很简单。 | 没有互动作用时直接给信息；保留真正需要回答的问题。 |
| What if I told you…、Here's what I mean… | 普通说明文可直接进入论点；访谈提问和对话按文体处理。 |
| 改变。突破。成长。这就是答案。 | 连续碎句只有抽象词时合并成完整意思，不强行发明具体成果。 |
| 每段都以“这才是真正的……”收尾 | 保留已有结论，删去重复升华；也允许自然地结束在事实或问题上。 |
| 所有句子都以“我们可以……”起头 | 依照内容调整主语和长短句，不按固定模板逐句替换。 |

## 主体与被动句

“团队在周三修复了导出错误”比“问题获得了完美解决”更清楚，前提是原稿已经提供团队、时间和修复事实。原稿只有“问题已解决”时，不能补造执行者或完成日期。

软件、设备、流程等可以作为准确的动作主体：“系统返回错误”“打印机输出三页”不必改成人的动作。对“投诉自然转化为修复”这种隐藏实际过程的表述，只有材料提供过程时才展开；否则保留原稿事实并指出需要澄清之处。

被动句可以突出对象或保留未知主体。“The request was rejected”不说明谁拒绝时，不能擅自改成“The administrator rejected the request”。也不要为了主动语态把“用户收不到邮件”改成“用户没有发送邮件”。

## 列表、标点与文体

三项列表恰好表达三件事时全部保留。破折号承担插入解释或转折作用时可以保留；副词表达速度、频率、程度时也可以保留。英语 Wh- 开头和中文省略主语都不自动构成问题。

根据逻辑关系和阅读节奏调整段落，不规定每段句数、列表项数或句长。口播可保留便于换气的短句，个人叙述可保留真实情绪，专业说明可保留定义明确的术语。

连续同长句、碎句堆叠、整齐排比或段段金句显得机械时，可以调整节奏；不为制造变化而改动准确的句子。删除“他说”等对话标签前，确认读者仍能识别说话人，必要语气和叙事节奏也没有丢失。
